# Archivo de versiones anteriores

La aplicación actual está en `App.js` y `src/`, con la configuración de Expo en la raíz del repositorio.

| Carpeta | Contenido |
| --- | --- |
| `previews/` | Exportaciones web anteriores, agrupadas con sus nombres originales |
| `prototypes/DeafApp2/` | Prototipo anterior con su configuración y documentación originales |

Estas copias conservan sus archivos originales para consulta. No se importan desde la aplicación actual ni son la entrada del despliegue. Para desarrollar o generar una versión nueva, usa los comandos de la [guía principal](../README.md) desde la raíz.

Las nuevas compilaciones se generan en `dist/`, que queda fuera de Git.
